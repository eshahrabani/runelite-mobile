# Core RuneLite plugins the Android host does not load, one FQCN per line.
#
# Read by downloadAndDexJar when it writes runelite-plugin-index.txt (the plugin
# list PluginManager.loadPlugins() is fed, because PluginManager's own Guava
# ClassPath scan cannot work on ART). Anything listed here is still present in
# the asset dex, it is simply never instantiated.
#
# Admission rule: the plugin needs lwjgl / JNA / a desktop-only library set (the
# Swing shell itself now runs in core/), a native web browser, or a desktop
# screenshot folder. Panels are no longer a reason to exclude a plugin: the
# sidebar hosts RuneLite's real Swing panels.
#
# BankTagsPlugin is deliberately NOT excluded: ClueScrollPlugin declares
# @PluginDependency(BankTagsPlugin) and PluginManager refuses to instantiate a
# plugin whose dependency is missing ("Unmet dependency for ClueScrollPlugin:
# BankTagsPlugin"), so excluding bank tags would cost the clue-scroll overlays too.
# WorldMapPlugin predates the sidebar. Unlike the other four entries, its bytecode
# (all 142 classes of net/runelite/client/plugins/worldmap/) references no
# lwjgl/JNA/jshell/FlatLaf/Discord/LinkBrowser/java.awt.Desktop symbol, so the
# admission rule above does not explain it. Kept excluded until it is re-evaluated
# against the Swing sidebar on a device; docs/plugin-runtime.md §3 says the same.
net.runelite.client.plugins.worldmap.WorldMapPlugin
net.runelite.client.plugins.gpu.GpuPlugin
net.runelite.client.plugins.devtools.DevToolsPlugin
