# Core RuneLite plugins the Android host does not load, one FQCN per line.
#
# Read by downloadAndDexJar when it writes runelite-plugin-index.txt (the plugin
# list PluginManager.loadPlugins() is fed, because PluginManager's own Guava
# ClassPath scan cannot work on ART). Anything listed here is still present in
# the asset dex, it is simply never instantiated.
#
# Admission rule: the plugin delivers its function through the desktop Swing
# client shell (config panel, plugin-owned window) or needs lwjgl / JNA / a
# desktop web browser. The native side panel replaces the shell; it cannot host
# foreign JPanels.
#
# BankTagsPlugin is deliberately NOT excluded: ClueScrollPlugin declares
# @PluginDependency(BankTagsPlugin) and PluginManager refuses to instantiate a
# plugin whose dependency is missing ("Unmet dependency for ClueScrollPlugin:
# BankTagsPlugin"), so excluding bank tags would cost the clue-scroll overlays too.
