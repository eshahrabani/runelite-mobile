# Code map

**Audience:** implementer
**Read this when:** you need to find which file owns a behaviour, or you are about to add, move, or delete a source file.
**Verified against:** `git ls-files android core hostshims tools ios .github`, `find core/src/main/java`, the class/Javadoc header of every file listed below, `android/build.gradle`, `.github/workflows/build.yml`, `android/plugin-exclusions.txt`, `android/hostlink-ignore.txt`, `android/hostlink-platform-extra.txt`

This is the per-file catalogue: what each source file owns and which loader consumes it. It is
the deepest level of the documentation set; the subsystem behaviour lives in the sibling pages
linked below each table.

## How to read this file

Every file below carries a marker describing its provenance and its build role. Read the marker
before editing anything.

| Marker | Meaning | How it is produced |
|---|---|---|
| `app` | Hand-written app code. Compiled by the `:android` module into the app dex. | `android/src/main/java/**` |
| `stub-hand` | Hand-written JVM/AWT/Swing replacement. Compiled by `:core` into the app dex. Edit in place. | `core/src/main/java/**`, no generator marker |
| `stub-gen` | Generated JDK stub. **Never hand-edit**; a `gen_stubs.py` run rewrites it. | `core/src/main/java/**` carrying the `Data-only stub for {@code ...}` / `Generated by tools/gen_stubs.py -- do not hand-edit.` header |
| `shim` | Hand-written replacement for an upstream `net.runelite.client.ui.*` (or `...plugins.config.*`) class. Compiled by `compileHostShims()` inside `android/build.gradle`, not by the app source set. | `hostshims/src/**` |
| `tool` | Build-time or developer tool, not shipped in the APK. | `tools/**` |

A file is treated as hand-written iff the marker string `Data-only stub for {@code` is absent from
its first 4096 bytes (the `MARKER` constant in `tools/gen_stubs.py`, applied by its file walk).
That convention decides what the generator skips and never overwrites: the skip check refuses an
existing marker-less target, and the stale-file cleanup deletes a file only when it *does* carry
the marker. See [tools.md](tools.md) for the generator itself and [core-stubs.md](core-stubs.md)
for the stub contract.

No table here lists line counts: they rot on every edit and were the part of this page that went
stale first. Use `wc -l` when a size actually matters.

## `hostshims/`

Marker: `shim`. Five `*.java` files, each one replacing an upstream class: four under
`hostshims/src/net/runelite/client/ui/` and one under `.../client/plugins/config/`. A shim's own
FQCN is the upstream class it replaces, so the "replaces" column repeats the package path. The
shims live outside the app source set because Guice resolves their signature types through the
asset (child) loader, and they are compiled by `compileHostShims()` in `android/build.gradle`, not
by the `:android` source set. For the *why* per shim and the three compiler rules, see
[plugin-runtime.md](plugin-runtime.md).

`net/runelite/client/ui/OSXFullScreenAdapter.class`, which deliberately has **no** shim — it is
simply absent, and its referrers are stripped too. `HOST_REPLACED_PREFIXES` strips the whole
`net/runelite/client/ui/laf/` tree for the same reason.
